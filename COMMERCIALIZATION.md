# Sprout Commercialization

## Positioning
A developer-facing multi-agent orchestration and coding-assistant framework. Commercialize only the capabilities that can be demonstrated reproducibly in a sandbox.

## Product paths
1. Open-source adoption funnel: examples, quickstart, benchmarks, issue templates.
2. Paid implementation sprint: adapt agent delegation, verification, memory and governance to one customer workflow.
3. Managed support: only after installation, reliability and support costs are measured.
4. Enterprise controls: auditability, policy gates, rollback and deployment support.

## Demo
Use a non-sensitive coding task with a visible plan, delegated subtasks, tests, and an audit trail. Show failed work being corrected rather than presenting only a perfect run.

## Acceptance before selling
- clean install on a supported environment
- repeatable sample run
- clear sandbox/permission boundaries
- tests for delegation failures, retries, loops and rollback
- documented data retention and tool permissions
- no claims of self-improvement quality without a benchmark

## Commercial status
DISCOVERY until a clean install and demo are verified. Do not imply that a managed hosted product exists unless deployed.
